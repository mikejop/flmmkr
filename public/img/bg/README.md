# Imagens de Background (`public/img/bg`)

Esta pasta é destinada exclusivamente para imagens de plano de fundo (backgrounds) da aplicação.

## Diretrizes:
- **Formato**: Todas as imagens nesta pasta devem ser no formato **WebP** (`.webp`).
- **Caminho de Uso**: No código, referenciar como `/img/bg/nome-da-imagem.webp`.
